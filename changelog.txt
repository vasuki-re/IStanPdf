changelog:
- LibreOffice Engine Optimization: Implemented Custom LibreOffice with unnecessary features disabled to reduce overall app size.
- Engine Pre-loading: Implemented async background pre-loading for the LibreOffice engine, which is disabled by default. If toggle is enabled from settings, it will improve performance during docx operations.
- iText 7 Migration: Completely replaced the heavy PdfBox-Android library with the modern, efficient iText 7 engine (AGPL) which reduced overall apk size.
- I/O Improvements: Removed the slow global PDFBoxResourceLoader.init() requirement. Upgraded PDF save streams in PdfStore to use a 64KB buffered output stream directly to Android's SAF URI.
- Dynamic Icons: Redesigned the accent icon switching mechanism. It now swaps the icon instantly in the background with a 500ms debounce when changing colors, completely eliminating the "App isn't installed" toast error and the need to restart the app.
- Improved M3 Design: Riced UI Design by micro optimizations.
- Fixed Split Range Logic: Fixed Split Range to sync with reordering of page changes and update range according to it, also changing order of pages updates ui.
- Status Bar Fix: Fixed a bug where the status bar color didn't match the active theme in settings by injecting applySystemBarTheme() into the SettingsActivity lifecycle.
- Donation Dialog Removed: Removed OneTime Donation Dialog to improve User Experience.
- UPI Donation Support: Added UPI Donation Support for Indian users.
